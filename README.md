# photoshop-color-desinger
# Колір і дизайн — інтерактивне завдання

Інтерактивне завдання з інформатики для **10 (11) класу**, курс «Комп’ютерна графіка».

**Теми:** «Колір. Теорія кольору. Колористика. Колірний круг», «Основи теорії дизайну» (§ 17–18).

## Зміст завдання

1. **Характеристики кольору** — яскравість, насиченість, ясність (світлість), кольоровий тон.
2. **Колірні моделі** — міксери RGB (повзунки R, G, B: жовтий, блакитний, пурпурний і білий) і питання про RGB, CMYK, HSB.
3. **Гармонія кольорів** — однотонна, споріднених та контрастних кольорів; основні поєднання.
4. **Психологія кольору** — вплив червоного, жовтого, зеленого, блакитного, чорного та білого кольорів.
5. **Основи теорії дизайну** — закони масштабу, пропорційності, контрасту; ритм, симетрія, асиметрія, динаміка; фактура; види композиції.
6. **Практична робота** — міні-редактор: учні відтворюють контрастну композицію за наведеним зразком (додавання фігур, переміщення, розмір, поворот, чорний/білий колір, сітка 50 × 50).

Усього 34 пункти оцінювання. Практична робота перевіряється автоматично за 4 критеріями порівняння зі зразком: кількість і види фігур, кольори фігур, розташування (допуск ≈ 40 пікселів), розмір і поворот (допуск ≈ 25 % і 12°). Для двох останніх критеріїв достатньо збігу не менш ніж 80 % фігур. Остаточно роботу оцінює вчитель.

## Як працює

- Учень вводить прізвище, ім’я та клас; запис про старт потрапляє в лист **«Реєстрація»** Google-таблиці.
- Кожне з 6 завдань відкривається на окремому екрані. Перемикатися можна номерами-вкладками (біля заповненого завдання з’являється ✓) та кнопками «Назад» / «Далі». Кнопки «Перевірити» і «Завершити» розташовані на останньому екрані.
- Після кнопки «Перевірити» показується лише кількість помилок і мотивуючий текст (без правильних відповідей). Можна перевіряти кілька разів.
- Після «Завершити» формується підсумок: бал, орієнтовна 12-бальна оцінка, кількість спроб, опис помилок і зображення створеної композиції.
- Кнопка **«Надіслати результат вчителю»** передає дані в таблицю, кнопка **«Зберегти результат»** зберігає підсумок як зображення.

## Налаштування

У файлі `index.html` на початку скрипта:

```js
const PROJECT='kolir-dyzain';   // назва проєкту (у таблиці)
const SCRIPT_URL='...';         // URL веб-застосунку Google Apps Script
const SECRET='';                // секретний ключ, якщо він використовується у скрипті
```

Дані надсилаються методом POST у форматі JSON: `project`, `action` (`start` або `result`), `surname`, `name`, `klass`, `date`, `time`, `score`, `grade12`, `attempts`, `errors`, `allErrors`, `details`.

## Публікація на GitHub Pages

1. Створіть репозиторій (наприклад, `kolir-dyzain`) і завантажте `index.html` та `README.md`.
2. **Settings → Pages → Deploy from a branch → main / (root)**.
3. Посилання буде виглядати так: `https://<користувач>.github.io/kolir-dyzain/`.

## Файли

- `index.html` — увесь проєкт в одному файлі (HTML, CSS, JavaScript).
- `README.md` — цей опис.

Для збереження результату як зображення підключається бібліотека html2canvas з CDN (потрібен інтернет).
